# W 声幕 · WDub

视觉风格采用深夜蓝、冰白、玻璃卡片和印泥金点缀；图标是「格中篆」WL 连写。支持亮色 / 暗色（设置 →「按钮与站点」→「外观」，默认跟随系统）；设置页、弹窗和本地播放器背景有静止的星点和雪花装饰，卡片上有小彩灯，可在同一处关闭。

给网页视频做**实时翻译 + 双语字幕 + AI 配音**的 Chrome 扩展。扩展和本地识别服务在自己的电脑运行；选择 Google、DeepSeek 等在线翻译或云语音服务时，文字或语音会按所选服务发送。无需 W 声幕账号；云服务使用你自己的 key 和额度。

## 方式一：只用扩展（推荐）

1. 打开 `chrome://extensions`，打开右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录下的 `extension/` 文件夹
3. 安装后会自动打开设置页，在「开始使用」里选一套方案：免费 / 推荐 / 全本地。所有 key 集中在「账号与 Key」页填写，每张卡片都有「去获取 key」直达链接和「测试」按钮

不需要 Node、Python 或任何额外服务。这一条路就是普通使用者的全部步骤。

## 方式二：加上本地语音识别（可选）

视频**没有字幕**时才需要。免费、不上传，但只在 Apple 芯片的 Mac 上可用。

```bash
bash tools/start-whisper.sh            # 英文等外语
bash tools/start-whisper.sh --sensevoice   # 再加上中文 / 粤语
bash tools/start-whisper.sh --check    # 只检查环境
```

首次运行会装依赖并下载模型（Whisper 约 1.6GB），之后离线可用。启动时终端会打印**连接口令**，填到 设置 →「语音识别」→「连接口令」。

每次启动会自动把 `yt-dlp` 更新到最新版（用于「识别人物」和无字幕流媒体的音频下载）。不想更新时加 `--no-update`。

## 方式三：开发与构建

需要 Node ≥ 20。

```bash
npm test          # 51 项行为测试
npm run test:stream   # 本地识别服务接口测试（Python）
node tools/build-mobile.mjs safari --out /tmp/wdub-safari    # 手机扩展
node tools/build-companion.mjs --out /tmp/wdub-companion     # 手机分享播放器
```

改完代码后，在 `chrome://extensions` 里点 W 声幕卡片上的刷新按钮，再刷新视频页即可生效。

## 方式四：手机版本（实验性）

`node tools/build-mobile.mjs safari|firefox` 会生成一份手机扩展，`node tools/build-companion.mjs` 会生成一个独立的手机播放器页面。**这两种产物都没有做过真机验收**，手机浏览器对音量、后台播放和自动播放的限制会导致配音表现和桌面不同。

### 适用范围与限制

- 目前主要面向桌面版 Chrome 中的 YouTube 和常见网页视频。网站的登录限制、受保护视频或特殊播放器可能导致字幕提取、音频识别失败；可尝试导入 SRT / VTT 字幕。
- `tools/start-whisper.sh` 的本地 Whisper 服务需要 Apple 芯片的 Mac 和 ffmpeg。其他电脑可在设置里选择支持的在线识别服务，并使用自己的 API key。
- DeepSeek、Azure、ElevenLabs 等在线服务可能按各自规则收费；具体额度和价格以服务商页面为准。

### 扩展申请了哪些权限，为什么

| 权限 | 用途 | 是否可选 |
| --- | --- | --- |
| `<all_urls>` | 在你打开的网页上放 W 按钮、读取播放器自己的字幕、替换成双语字幕层。只有页面里存在视频时才会动作 | 否。不支持任意网站的代价就是只做白名单站点 |
| `storage` / `unlimitedStorage` | 保存设置、术语表（约 1.4MB）、翻译与识别缓存 | 否 |
| `tts` | 用系统自带语音（Chrome 内置 + macOS 系统声音）朗读，零配置 | 否 |
| `offscreen` | 在扩展自己的隐藏页面里合成和播放配音音频，绕开网页的 CSP 限制，B 站、课程站才能出声 | 否 |
| `contextMenus` | 右键菜单「用 W 声幕配音这个视频」 | 否 |
| `declarativeNetRequestWithHostAccess` | 只对**你配置的本机 Ollama 地址**去掉 `Origin` 头，否则 Ollama 会 403 | 否 |

扩展不会读取你的浏览记录，也不会上传视频文件。完整的数据去向和删除方式见[隐私说明](PRIVACY.md)。

## 怎么用

| 操作 | 方式 |
|---|---|
| 开始 / 停止 | 点播放器控制栏里的 **W** 按钮（YouTube 和其他网站一样）。默认是「中文配音 + 字幕」，想只翻字幕不配音，在面板或设置 →「按钮与站点」里把「点 W 时」切到「只翻字幕」，运行中切换立即生效 |
| 只翻字幕的效果 | 先翻译当前位置附近的字幕并显示，其余在后台继续翻译；未翻到的句子暂时显示原文。视频保持原来的播放或暂停状态，不会自动开始播放 |
| 快捷设置 | W 旁边的星光滑杆按钮，或屏幕右边的 W 悬浮球（全屏也能用）。工具栏弹窗会显示当前页面的状态 |
| 快捷键 | `Alt+D` 配音、`Alt+T` 只翻字幕。在设置 →「按钮与站点」→「修改快捷键」里改 |
| 原声 | 面板里选「保留原声」（配音说话时自动压低）或「静音原声」（只听中文） |
| 切换字幕 | `Alt+C`：双语 → 仅译文 → 关闭 |
| 原声 / 配音切换 | `Alt+S` |
| 没有字幕的视频 | 快捷设置面板 →「导入字幕」载入 SRT / VTT |
| 本地视频 | 弹窗 →「本地视频配音」，把视频和字幕一起拖进去 |
| 导出译文 | 快捷设置面板 →「导出译文」得到目标语言 SRT |
| 视频总结 | 快捷设置面板 →「视频总结」（需配置大模型） |


## 引擎选择（推荐配置）

设置页「开始使用」里的三套方案对应下表；也可以在「翻译」「语音与角色」「语音识别」各页单独选。每项只留一个免费的加一两个好用的，选项少、好挑；只有一个模型的不显示下拉。

| | 免费方案 | 推荐方案 |
|---|---|---|
| 翻译 | Google 翻译，零配置 | **DeepSeek**：更口语化，支持术语表，能识别说话人和性别；也可选 **Gemini**（有免费额度） |
| 语音 | 系统声音（Chrome 内置 + macOS 系统声音） | **Azure 神经语音**，用自己的 Free F0 key；追求音质可用 **ElevenLabs**。额度与价格以服务商页面为准（2026-11 时 Azure 免费层为每月 50 万字，ElevenLabs 免费层约 1 万字符，可能变动） |
| 全本地 | — | [Ollama](https://ollama.com/download) 翻译 + 系统声音 + 本地识别。翻译和识别都在本机推理，字幕不离开这台电脑；首次下载模型、启动识别服务时的依赖更新仍需联网。Ollama 不可用时会直接报错并重试，不会自动改发 Google 翻译（设置 →「翻译」里可手动打开「云端备用」） |

**Ollama**：设置页只列出你已经下载的模型。推荐腾讯混元的翻译专用模型（约 1.1GB，M1 上每句 0.5～0.8 秒）：`ollama pull Dreagonmon/hy-mt1.5:1.8b`。翻译专用模型会逐句直译（术语表照样生效），但不会判断说话人，也做不了视频总结。扩展会自动处理 Ollama 的来源限制，不用改 Ollama 的配置。

**角色声音**：开启「多角色配音」后，字幕里的 `[人名]`、`人名：`、`>>` 都会被识别为换人。用 AI 翻译时，模型还会判断每句话的说话人和性别，男声池、女声池会自动轮流分配，同一个人始终用同一个声音。

**人物纠错**：配音声音面板会显示播放位置附近的当前字幕句。可跳到上一句或下一句，改这句的说话人及该人物的男声／女声，点「保存这句」。修正按视频保存；当前正在朗读的句子重新播放后使用新声音。自动识别人物时，已保存的逐句修正会继续生效。

## AI 语音识别（视频没有字幕时）

在设置 →「语音识别」里选引擎：

| 引擎 | 什么时候用 |
|---|---|
| **本地 Whisper**（默认） | 日常使用：免费、不限量、不上传。在 M1 上大约是 3～4 倍速（1 小时视频约 15～20 分钟） |
| **ElevenLabs Scribe** | 多人对话、访谈：在我们自己的样本里准确率最好，还能区分说话人，每个人自动配不同声音。和配音共用同一个 key。这是本地对比结论，没有做大规模评测 |
| **本地 SenseVoice · 中文** | 中文、粤语视频：免费、不上传。实测比 Whisper 准、快约 2.5 倍 |

**启动本地识别服务**（第一次运行会自动安装依赖并下载模型）：

```bash
bash tools/start-whisper.sh
```

上面这条只启用 Whisper。要识别中文，加上 `--sensevoice`（首次会多装 FunASR，并从 ModelScope 下载约 900MB 模型）：

```bash
bash tools/start-whisper.sh --sensevoice
```

服务地址是 `http://127.0.0.1:8199/v1`，只监听本机。启动时终端会打印一串**连接口令**，要填到 设置 →「语音识别」→「连接口令」；没有口令的请求一律拒绝（包括本机其他程序和其他扩展）。Whisper 和 SenseVoice 共用这一个服务，按设置里选的引擎自动切换。换更快的小模型：`bash tools/start-whisper.sh --model mlx-community/whisper-small-mlx`

> 8GB 内存的 Mac 同时加载 Whisper 和 SenseVoice 两个模型时会变慢。只看中文视频时，可以只用 SenseVoice（选它就不会加载 Whisper）。

**怎么触发识别：**
- 本地视频：在「本地视频配音」页选好视频，点「✦ AI 识别字幕」。识别完可以导出原文 SRT
- 网页视频：没有字幕时，开始配音会先尝试直接识别视频文件；流媒体网站会请本地识别服务按网页地址提取音频后识别。识别完成先显示字幕校对窗口，可逐页改错字、清空误识别的行，确认后才翻译和配音。流媒体路径目前支持本地 Whisper / SenseVoice，需保持 `tools/start-whisper.sh` 服务运行；登录限制、直播或网站阻止下载时仍可能失败，可改用本地视频页导入。

同一个视频识别过一次后会缓存，下次直接使用。

## 本机 Codex CLI（实验性）

「视频总结」可以用你自己装在本机的 Codex CLI 来跑，字幕不出这台电脑。**这是实验功能，默认不启用，普通使用不需要它。**

- 需要你自己安装 [Codex CLI](https://github.com/openai/codex)，并确认终端里 `codex` 命令可用
- 启动桥接：双击仓库根目录的 `启动学习纪要Codex.command`，或运行 `node tools/study-codex-server.mjs`
- 它只监听 `127.0.0.1:8198`，启动时打印**连接口令**；把口令填到 设置 → 视频总结 →（服务商选 Codex）→「本机连接口令」
- 子进程用 Codex 的 `read-only` 沙箱，并且只继承 `PATH`、`HOME` 等必要环境变量

**已知边界**：「不要使用工具、不要读文件」目前主要靠提示词和沙箱约束。我们还没有针对「恶意字幕诱导读取本机文件」做过完整验证，所以标为实验功能。你不能接受这个边界时，改用云端大模型或本地 Ollama。

## 换电脑 / 备份

- **设置和术语库**通过 Chrome 同步自动带到新电脑：新电脑的 Chrome 登录同一个 Google 账号并开启同步，装好扩展后就会出现。key 不会进同步
- **key** 用「按钮与站点」→「备份与迁移」→ 勾选「包含 key」导出。key 用你设的密码加密（PBKDF2 + AES-GCM），导入时输入密码解锁
- 翻译缓存和识别结果不带走，重新看视频时会自动生成

## 设计特点

- **不依赖任何私有服务器**：翻译、语音、字幕处理都走你自己的接口，没有会员、额度和每天 5 个视频的限制
- **对齐更自然**：配音太长时，先把语速加快（音调不变）；加到上限还放不下，才让画面暂时变慢
- **智能闪避**：只在配音说话时压低原声，句子之间恢复，背景音乐和现场感都保留
- **按性别分配角色声音**：由大模型判断说话人和性别，不用手动建说话人列表
- **语音在扩展自己的页面里播放**：不受网页安全策略（CSP）限制，B 站、课程站这些都能出声
